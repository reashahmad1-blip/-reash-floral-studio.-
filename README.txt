REASH FLORAL STUDIO — Android-friendly starter app

WHAT THIS IS
A responsive website app (PWA) with a luxury black-and-gold theme. On Android, it can be added to the home screen and opens in an app-like full-screen window.

IMPORTANT CUSTOMIZATION
1. Open index.html in a text editor.
2. Find: const WHATSAPP_NUMBER = "910000000000";
3. Replace it with your WhatsApp number including country code, digits only.
   Example format for India: 919876543210
4. Replace @your_instagram_here with your Instagram username.
5. Replace the sample photos/text with your real portfolio and services.

HOW TO PUT IT ONLINE FOR FREE
The app needs HTTPS hosting for installation as a PWA. A simple option is GitHub Pages:
- Create a GitHub account and a new public repository.
- Upload all four files plus README.txt from this folder.
- In repository Settings > Pages, enable deployment from the main branch.
- Open the published HTTPS website on your Android phone in Chrome.
- Chrome menu (three dots) > Add to Home screen / Install app.

NOTE
This starter package is not a Play Store APK. It is an installable Android home-screen web app. A Play Store APK needs an additional Android build/signing process.
